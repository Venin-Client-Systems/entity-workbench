## Scope clarification

The implementation request was clarified to prohibit external search providers. Direct public website collection and application-owned local indexing are authorised. There is no provider-selection dependency or API-key setup. The broader open-web coverage requirement is still unproven; a small collected corpus does not satisfy it.

## Gate policy

The release checker fails while any required gate is unpassed. A successful source build, local engine test or development sandbox probe must not be relabelled as a complete approved release. Development `.app` builds are not signed/notarized product releases.

The [versioned acceptance ledger](release-evidence/README.md) now binds observations to exact source, installer, acceptance-policy and fixture-catalogue hashes. Required OS versions, retained negative outcomes, review receipts and freshness are checked before qualification. The repository still contains no release candidate or acceptance observations; all twelve gates remain unpassed. Ten small synthetic inputs establish initial regression expectations, not completed end-to-end scenarios.

## OCR word-region engine — 24 September 2026

The separate opt-in [word-region engine](security/OCR-WORD-REGIONS.md) returns bounded page/block/paragraph/line/word boxes relative to the assigned raster, exact word text and explicitly uncalibrated Tesseract confidence. A fixed recipe produces paired text/TSV outputs using the existing inventoried English runtime. Rust checks hierarchy, order, bounds, unique identities, finite scores, complete rows, text agreement and exact raster/output bindings. Existing text-only OCR, job and extraction schemas remain unchanged. This engine creates no accepted facts or original-document anchors and does not yet persist regions in canonical jobs.

Clean integrated source `2fa8737c318ff7538d3e1c06e9f0fad55b1b143a` passed **154 ordinary Rust tests** (20 native/runtime cases explicitly excluded), strict Clippy, five portable failure/history evidence cases and **eight native region/contract tests** on macOS 26.6.2 arm64. It includes actual recognition with word boxes covering raster ink, blank input, malformed/oversized/truncated output, hostile access, direct networking, cancellation/reaping and output limits. The separately signed increment also passed all eight legacy native OCR checks, release/debug Clippy, unchanged schema generation and bounded independent code review.

Paired output validation cannot establish recognition accuracy or detect a worker that fabricates mutually consistent text and regions. The portable failure recorder is included in all three source-CI targets; source compilation does not qualify runtime confinement. No complete-release gate passes from this increment.
