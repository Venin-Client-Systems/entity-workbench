# ADR 0001 — canonical Rust ownership

Status: accepted architecture; implementation partial.

Retain Rust/Tauri with specialist Java and Python adapters. Canonical workspace writes, permissions, provenance and domain validation belong in Rust. Lucene and DuckDB are rebuildable projections, not competing authorities. Original source bytes are immutable by application convention and verified before backup/report export. Operating-system confinement is required to protect them from compromised processing workers.

Separate parser and search processes. No generic shell, plugin, Python or SQL execution is exposed to users or downloaded recipes. No telemetry, crash-upload or updater plugin is installed.
