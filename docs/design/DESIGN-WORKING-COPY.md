# Design recovery and editable working copy

On 25 September 2026, the original [Entity Workbench design file](https://www.figma.com/design/O50ISV0LGG8nKDcFORNMbO) became responsive after sign-in. The signed-in account had view-only access. Its layer list and [ledger frame 57:2](https://www.figma.com/design/O50ISV0LGG8nKDcFORNMbO?node-id=57-2) were inspected after that fresh load. The frame reports 1120×1140 and shows the industrial filter controls, applied scope, five joined count instruments, source rows, complete export and save receipt previously documented in [Ledger scope](LEDGER-SCOPE.md). No unsynced warning was visible in this recovered view.

This establishes remote readback of that saved frame, resolving its earlier timed-out persistence check. It does not establish that every previously unsynced edit survived; those edits lacked a complete independent baseline. The historical timeout and original authoring/export evidence remain retained.

Figma's Duplicate to your drafts action then created [an editable working copy](https://www.figma.com/design/CphN4aTS8IXSVlKX7zDJtg), currently named **Entity Workbench — design system and workflows (Copy)**. Native Chrome inspection confirmed the new file URL, Design tab, editable page-fill fields, creation tools, retained frame strip and five reusable components. The original file was not replaced and its sharing permissions were not changed.

The browser connection dropped while returning from duplication. Native readback established that creation had completed, avoiding a blind duplicate retry. Later native click/coordinate controls did not become usable. Renaming, new DOCX frames and an independent reopen of the working copy remain pending. This is a recovered design workspace, not final visual approval or completion of the remaining compact/state frames. Future authoring should use the working-copy URL and record new frame links explicitly; historical frame citations continue to identify the original file.
